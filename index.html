2.1 Pip · Tick · Contract Size

Pip

ឯកតាចលនាតម្លៃរូបិយប័ណ្ណ។ គូភាគច្រើន 1 pip = 0.0001 (ខ្ទង់ទី ៤)។ គូ JPY 1 pip = 0.01។ ខ្ទង់ទី ៥ (ឬទី ៣ សម្រាប់ JPY) ហៅថា Pipette។

Tick

ចលនាតម្លៃតូចបំផុតដែលទីផ្សារអនុញ្ញាត។ សម្រាប់មាស និងប្រេង ជាទូទៅ 0.01។

2.2 Leverage, Balance, Equity, Margin

Leverage

អនុញ្ញាតឲ្យគ្រប់គ្រងទំហំទីផ្សារធំជាងទឹកប្រាក់ដែលមាន។ Leverage 1:100 មានន័យថា $1 គ្រប់គ្រងបាន $100។ វាពង្រីកទាំងចំណេញ និងខាត។

Balance

ទឹកប្រាក់ក្នុងគណនី មិនទាន់រាប់ចំណេញ/ខាតនៃការជួញដូរដែលកំពុងបើក។

Equity

តម្លៃគណនីពិតបច្ចុប្បន្ន រាប់បញ្ចូលចំណេញ/ខាតដែលកំពុងបើក (Floating P/L)។

Used Margin / Free Margin

Used Margin = ទឹកប្រាក់ត្រូវចាក់សោ ដើម្បីបើកការជួញដូរ។ Free Margin = ទឹកប្រាក់នៅសល់សម្រាប់បើកការជួញដូរថ្មី។
Notional Value = Lots × Contract Size × Price (USDJPY: Lots × 100,000 គិតជា USD) Used Margin = Notional Value ÷ Leverage Equity = Balance + Floating P/L Free Margin = Equity − Used Margin Margin Level % = (Equity ÷ Used Margin) × 100
ឧទាហរណ៍៖ Gold 1 Lot ត្រង់ 4000.00, Leverage 1:100 → Notional = 100 × 4000 = $400,000 → Used Margin = $4,000។ បើ Balance $10,000 គ្មាន Floating P/L → Margin Level = 10,000 ÷ 4,000 × 100 = 250%។
Margin Call / Stop Out៖ នៅពេល Margin Level ធ្លាក់ទាប broker នឹងព្រមាន (Margin Call) ហើយបិទការជួញដូរដោយស្វ័យប្រវត្តិ (Stop Out) ។ ភាគរយកំណត់ខុសគ្នាតាម broker (ឧ. 100% / 50%)។

3.1 Market Execution និង Pending Orders

Buy (Long)

ទិញភ្លាមតាមតម្លៃ Ask ដោយរំពឹងថាតម្លៃឡើង។

Sell (Short)

លក់ភ្លាមតាមតម្លៃ Bid ដោយរំពឹងថាតម្លៃធ្លាក់។

Pending Order គឺបញ្ជាដែលដាក់ទុកមុន ហើយនឹងដំណើរការនៅពេលតម្លៃទៅដល់ចំណុចកំណត់។

បញ្ជាទីតាំងធៀបតម្លៃបច្ចុប្បន្នគំនិត
Buy Limitក្រោម តម្លៃបច្ចុប្បន្នទិញថោក រង់ចាំតម្លៃងាកឡើង (Reversal)
Sell Limitលើ តម្លៃបច្ចុប្បន្នលក់ថ្លៃ រង់ចាំតម្លៃងាកចុះ (Reversal)
Buy Stopលើ តម្លៃបច្ចុប្បន្នទិញពេលតម្លៃបំបែកឡើង (Breakout)
Sell Stopក្រោម តម្លៃបច្ចុប្បន្នលក់ពេលតម្លៃបំបែកចុះ (Breakout)

3.2 Take Profit (TP) និង Stop Loss (SL)

🎯 Take Profit

  • Buy → TP លើ តម្លៃចូល
  • Sell → TP ក្រោម តម្លៃចូល

🛑 Stop Loss

  • Buy → SL ក្រោម តម្លៃចូល
  • Sell → SL លើ តម្លៃចូល
ច្បាប់មាស៖ កំណត់ SL រាល់ពេលបើកការជួញដូរ ហើយដាក់ SL នៅចំណុចដែលបញ្ជាក់ថាគំនិតជួញដូររបស់អ្នកខុស (ឧ. ក្រោម Support) មិនមែនដាក់តាមចំនួនប្រាក់ដែលចង់ប្រថុយនោះទេ។

3.3 ច្បាប់គ្រប់គ្រងដើមទុន

1–2% Rule

ប្រថុយមិនលើស 1–2% នៃ Balance ក្នុងមួយការជួញដូរ។ បើ Balance $10,000 ហានិភ័យអតិបរមា = $100–$200។

Risk-to-Reward (RR)

គោលដៅ 1:2 ឬ 1:3 មានន័យថា ប្រថុយ $1 ដើម្បីរក $2 ឬ $3។

Win Rate ដែលត្រូវការដើម្បីស្មើដើម (Break-even)

Break-even Win Rate = 1 ÷ (1 + RR) (មិនរាប់ spread/commission)
